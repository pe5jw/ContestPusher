ContestPusher
Upload je contest log naar alle grote ham radio diensten in één klik.

Ondersteunde diensten

  • Logbook of the World (LoTW) — via TQSL
  • eQSL.cc — directe HTTP upload
  • QRZ Logbook — REST API (betaald abonnement vereist)
  • Club Log — ADIF upload API
  • HRDLog.net — REST API

Gebruik

Configureer je diensten onder "Services", upload daarna je ADIF bestand en ContestPusher stuurt het parallel naar alle ingeschakelde diensten.

Open Source

ContestPusher is volledig open source (MIT licentie). De broncode staat op GitHub. Bijdragen zijn welkom!

ContestPusher is gratis en open source. Vind je het nuttig? Een kleine donatie helpt de ontwikkeling gaande te houden. 73!
